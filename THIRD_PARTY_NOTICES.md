# Third-Party Notices

Hakyking uses third-party Python packages listed in `requirements.txt` and
`requirements-dev.txt`. Each dependency remains under its own license.

Optional runtime tools are deliberately not bundled in this source snapshot:

- FFmpeg / FFprobe: used for probing and extracting audio from video.
- Rubber Band: used for pitch and time processing when selected.
- RMVPE model files: optional pitch tracking assets supplied separately by the
  user under their own applicable terms.

Before redistributing a packaged build, include the notices and licenses for
every binary, model, font, and library actually bundled into that build.
