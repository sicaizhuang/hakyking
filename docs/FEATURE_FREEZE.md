# Hakyking 功能冻结基线

从本文件建立起，Hakyking 暂停增加新工具，先稳定现有工作流。

冻结保留的能力：

- 素材文件夹与音频导入
- 自动切片与手动切片
- 音轨区和工作区
- 音高块与音高曲线
- V（控制点选择/移动）、B（控制点添加/删除）、N（颤音区域）
- 颤音参数、播放、工程保存与读取

冻结期间允许的改动：修复缺陷、整理数据边界、性能优化、测试与兼容迁移。
任何新工具必须等 V/B/N 的职责、撤销重做和三份固定样本全部验收后再进入开发。

## 稳定化工具契约

- V 只选择、移动和框选音高控制点。按住 Ctrl 可多选；选中至少两个点后，它们之间真实连续的曲线段才进入“已选曲线段”状态。V 不添加或删除点。
- B 只添加或删除控制点。左键在曲线上添加，右键在控制点上删除；B 不移动或选择控制点。
- N 只编辑已经选中的曲线段上的参数化颤音。没有已选曲线段时不能启动，也不能自动替用户选择曲线。
- V 的移动、B 的添加/删除、N 的颤音写入都必须进入全局撤销栈，支持 Ctrl+Z / Ctrl+Y。

三份固定验收素材和命令见 `docs/ACCEPTANCE_SAMPLES.md`。冻结期的快速门禁不得临时换素材。
